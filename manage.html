Add a film.

Upload your video to YouTube first, then add its link here. Public and unlisted videos work if embedding is enabled. Private videos will not play for visitors.

This form prepares a public GitHub entry. Sign in as Shaxsi and click Create on GitHub to publish it. Only entries created by Shaxsi appear in the portfolio.

Edit or remove a film

Open your video entries on GitHub. Edit an entry to change its title, link or description. Keep the [Portfolio video] title prefix and the YouTube link on the first line. Close an entry to remove it; reopen it to restore it. Refresh the portfolio to see changes.

Video links and descriptions are public, including links to unlisted videos. Playback is hosted by YouTube. The portfolio uses GitHub’s public API, so temporary API limits can affect loading.
